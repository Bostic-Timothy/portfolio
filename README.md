# Portfolio

Personal cybersecurity technical portfolio for documenting security practice,
technical methods, and future lab-based case studies.

## Structure

- `index.html` - Main portfolio page
- `offensive.html` - Offensive security methodology and planned case-study areas
- `css/` - Stylesheets
- `js/` - JavaScript project data and page behavior
- `assets/images/` - Sanitized image assets
- `assets/documents/` - Documents and future resume materials
- `projects/offensive/` - Future offensive security case studies
- `projects/cyber-range/` - Future cyber range and security engineering projects
- `projects/detection/` - Future detection and incident response projects
- `projects/automation/` - Future security automation projects

The project directories are intentionally empty until evidence-backed work is
ready to document. No client engagements, findings, metrics, screenshots, or
other project outcomes should be added without supporting evidence and proper
sanitization.

## Case study outline

Future offensive case studies should document, where applicable:

- Objective and scope
- Environment
- Methodology and attack path
- Sanitized evidence
- Findings and impact
- Remediation and detection opportunities
- Lessons learned
